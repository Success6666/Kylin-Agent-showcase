# 七分钟展示与答辩演示

演示基线为 Kylin Agent v1.0.2。准备两个受管节点、一个只读排查请求和一个可回退的变更目标，打开聊天、告警、审批、Trace、知识与评测页面。

| 时间 | 展示内容 | 可观察结果 |
| --- | --- | --- |
| 0:00–0:45 | 定位与分层架构 | 面板、认证、控制面、两个节点和 RabbitMQ 分工 |
| 0:45–2:00 | 只读排查 | 主模型按需发现工具，读取观察，阶段和证据实时更新 |
| 2:00–2:45 | 运行中交互 | 补充引导，回答信息缺口并恢复原会话 |
| 2:45–3:45 | 变更审批 | 预览 diff，核对参数与节点，逐动作批准，执行后验证 |
| 3:45–4:30 | 告警与飞书 | 等待研判，主动生成方案，批准具体动作 |
| 4:30–5:15 | 两级 Trace | 下钻模型、工具与 Harness，查看用量、耗时和证据 |
| 5:15–6:00 | 经验与核心记忆 | 待审草稿、修订发布、来源案例、限量核心与事实有效期 |
| 6:00–7:00 | 评测与开发取舍 | 900 条当前数据、抽样与召回测量，以及 Git 演进 |

变更演示使用可销毁测试目标，逐动作核对工具、完整参数、节点、风险及回退信息。回放展示当前账号可见且脱敏的记录。

评测页展示范围、来源、已测数量、状态、延迟及提供商用量。当前 6 例待业务复核，150 查询资料源召回已测量，历史故障报告待复验，缺失用量显示 `null`。

补充演示可展示 SSE 重连、重复请求复用、取消、版本冲突与 UNKNOWN 结果核对。开发过程详见 [Git 取舍](development-decisions.md)。
