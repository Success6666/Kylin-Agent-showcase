# Trace 工作台与事件回放

Trace 工作台提供业务流程与组件调用两级视图。业务视图展示请求、处理轮次、引导、提问、审批和结果，组件视图展示模型请求、工具调用、耗时、用量与 Harness 结论。

## 两级定位

`GET /api/events/{trace_id}/graph` 返回 `views.business` 与 `views.components`。业务步骤通过 `component_ids` 下钻到实际调用；组件合并同一调用的开始与结束，保留观察和原始证据入口。

每轮先显示“分析请求与已有证据”，选定工具后更新为磁盘排查、日志分析或审批准备等实际阶段。聊天与业务图使用同一阶段记录。旧 Trace 根据已有工具记录生成标签，缺失信息显示相应状态。

## 交互与展示

- 横向 Mermaid 画布支持搜索、异常定位、步骤导航、起终点跳转、拖动和缩放。
- 默认字号为 100%，小图居中，较长流程横向滚动；概览模式按画布尺寸适配。
- 窗口变化保留手动缩放，渲染失败时使用横向备用视图。
- 时间顺序用虚线，记录的父子关系用实线。
- 模型回答使用本地 Marked 与 DOMPurify 渲染，表格和代码块支持横向滚动。

## 事件与恢复

`trace_id` 关联任务，`request_id` 关联请求账本，`event_id + sequence` 标识顺序。SSE 重连通过 `Last-Event-ID` 补读，普通阶段事件可合并，终态、审批、错误和取消进入可靠缓冲。

回放从已落库、已授权并脱敏的事件、任务和审计记录生成，关联任务按当前账号与节点权限独立核验。运行中引导、用户回答和审批恢复进入业务 Trace，便于回看目标变化、人工参与与最终证据。
